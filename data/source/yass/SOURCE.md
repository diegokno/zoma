# Source

The figure descriptions in this directory were copied from the `figures`
directory of [thanks4opensource/yass](https://github.com/thanks4opensource/yass),
with repository history current on 2026-09-25. The local build validates and
deduplicates the collection. Only 81 imported forms satisfy the application's
single connected-object rule; generated replacements bring the catalog to 120.

The upstream project is licensed under GNU GPL v3 or later. These files are
included only for local product exploration. Review the upstream license before
redistributing this prototype or replace this sample catalog with independently
generated figures.
